🎵 SoundCloud Player

Web Component Player with OAuth Authentication

Getting Started

  1. Click "Connect with SoundCloud" to authenticate (only needed once)
  2. Paste a SoundCloud track URL in the input field below and click "Add Player"
  3. Use the play button to stream tracks
  4. Like and comment on tracks (requires authentication)
Note: Enter SoundCloud URLs in the format: https://soundcloud.com/artist/track-name or shortened form (e.g., https://on.soundcloud.com/xyz123)

🔧 Token Refresh Testing

Ready for testing. Steps: 1. Click "Simulate Token Expiry" to clear the access token (keeps tokenKey) 2. Try to play a track - should auto-refresh and work 3. Or click "Manually Refresh Token" to trigger refresh directly
